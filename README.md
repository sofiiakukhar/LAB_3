# Лабораторна робота №3. Основи регресійного моделювання

Дослідження залежності ринкової вартості житлової нерухомості (`Price_USD`) від житлової площі та географічної локації у 8 мегаполісах США.

## Структура репозиторію
* `data/house_prices_large_dataset.csv` — вихідний набір даних ($N = 50\,000$).
* `notebook/EDA.ipynb` — виконуваний ноутбук із покроковим розвідувальним аналізом, діагностикою та моделюванням.
* `reports/report.qmd` та `reports/report.html` — вихідний код і зібраний HTML-звіт Quarto.
* `reports/slides.qmd` та `reports/slides.html` — вихідний код і зібрана презентація (Quarto Revealjs).
* `renv.lock` — зафіксовані версії R та пакетів.

## Вимоги до середовища
* **R:** версія `4.6.1`
* **Quarto:** версія `1.5+`
* **Основні пакети R:** `tidyverse`, `rsample`, `broom`, `sandwich`, `lmtest`, `knitr`, `scales`, `patchwork`
